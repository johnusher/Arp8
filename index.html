ARP8 user manual · v0.1

browser MIDI arpeggiator for the Korg phase8

quickstart

  • Open in Chrome or Edge. Safari and Firefox don't support Web MIDI as of 2026.
  • Plug in your phase8 via USB-C (or any USB-MIDI device). Allow the MIDI prompt.
  • Hit TEST in the transport — you should hear C3 and see bytes in the MIDI monitor at the bottom.
  • Click a chord pad — the arp starts. Click another to switch chords.

phase8 setup

  • Phase8 ships in STATIC mode: slots 1–8 listen on MIDI 36–43, regardless of the resonators you've installed. ARP8 defaults to this — no synth-side config needed.
  • If you've put your phase8 in FREQUENCY mode (calibrated via SELECT + power-on), switch the p8 mode dropdown to pitch · calibrated.
  • Default install assumed: 8 C-major resonators, C3 → C4. Edit phase8Tines() in src/chords.js for custom layouts.

playing

  • Chord pads — click to arm a diatonic chord. Latch on (default) keeps it armed; off = hold to play.
  • Pattern — pick the arpeggio shape (up / down / converge / random / chord / etc.).
  • Knobs — drag vertically to adjust. Hold Shift for fine. Scroll wheel works too.
  • Step grid — click cells to mute beats; right-click to clear.
  • Snap to tines — quantises any chord note onto an installed resonator pitch.

songs

  • 8 bundled compositions: Tines & Time, Prelude (Bach), Pulse (Reich), Drift (Eno), Driver (Carpenter), Gymnopédie (Satie), Indeterminacy (Cage), Choral (Pärt).
  • ◀ ▶ chevrons in the transport cycle through the catalogue.
  • SONG button starts / stops the current song. Songs loop forever.
  • Cycling while playing hot-swaps to the new song. Pressing a chord pad aborts the song.

keyboard

  • Space play / stop
  • 1–7 chord pads
  • Esc panic (all notes off)
  • ? open / close this manual
